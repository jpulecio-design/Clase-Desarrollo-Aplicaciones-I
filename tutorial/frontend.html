Frontend

¿Qué es el Frontend?

El Frontend es la parte de una aplicación web o software que el usuario ve e interactúa directamente. Es todo lo que ocurre en el navegador del usuario: la estructura visual, los colores, los botones, las animaciones, los formularios y la respuesta a cada clic.

Se le conoce como "el lado del cliente" porque todo su código se ejecuta en el navegador del usuario (Chrome, Firefox, Edge, Safari), no en el servidor. Su objetivo principal es ofrecer una experiencia de usuario (UX) clara, atractiva y funcional.

¿Desde qué año existe?

  • 1991: nace la primera página web con HTML básico, creada por Tim Berners-Lee. Solo había texto e hipervínculos.
  • 1995: aparece JavaScript (creado por Brendan Eich en Netscape). Ahora la web puede reaccionar a clics y validar formularios.
  • 1996-1999: se populariza CSS para separar el diseño del contenido.
  • 2005: nace AJAX, permitiendo cargar datos sin recargar la página (base de las apps modernas).
  • 2010 en adelante: auge de frameworks como React, Vue y Angular, y el concepto de Single Page Application (SPA).

Características principales

  • Interactividad: responde a las acciones del usuario en tiempo real.
  • Responsive: se adapta a móviles, tablets y escritorios.
  • Accesibilidad: debe poder usarse por cualquier persona.
  • Rendimiento: debe cargar rápido y consumir pocos recursos.
  • Compatibilidad: debe funcionar en distintos navegadores.
  • Separación de responsabilidades: HTML estructura, CSS estilo, JS comportamiento.
Dato clave: el frontend trabaja en conjunto con el backend (el lado del servidor), comunicándose mediante APIs bajo el modelo petición-respuesta.

Lenguajes Base

Existen tres lenguajes base que todo desarrollador frontend debe dominar, más algunos extras:

HTML5
Año 2014 HyperText Markup Language. Lenguaje de marcado que define la estructura de la página: títulos, párrafos, imágenes, enlaces y formularios.

No es un lenguaje de programación, es de marcado.
CSS
Año 1994 Cascading Style Sheets. Lenguaje de estilos que controla la apariencia visual: colores, tipografías, márgenes, animaciones y diseño responsive.

Permite separar el diseño del contenido.
JavaScript
Año 1995 Lenguaje de programación que da comportamiento a la página: manejo de eventos, peticiones a APIs, animaciones y validaciones.

Es el único lenguaje que corre nativamente en el navegador.
Frameworks y librerías modernas
Años 2011-2019
  • React (Meta) – el más usado hoy en día.
  • Vue.js – fácil de aprender, muy popular en Latinoamérica.
  • Angular (Google) – robusto, ideal para empresas grandes.
  • Svelte – compila a JavaScript puro, muy rápido.
  • Bootstrap / Tailwind CSS – frameworks de estilos.
  • TypeScript – JavaScript con tipos, muy usado en proyectos grandes.
Regla de oro: aprende bien HTML, CSS y JavaScript puro antes de saltar a un framework.

Ejemplo práctico de Frontend

Este código combina HTML + CSS + JavaScript en un solo archivo:

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Ejemplo Frontend</title>
    <style>
        body { font-family: Arial; background: #f0f0f0; text-align: center; }
        #contador { font-size: 3rem; color: #0d6efd; }
        button { padding: 10px 20px; font-size: 1.2rem; cursor: pointer; }
    </style>
</head>
<body>
    <h1>Mi primer Frontend</h1>
    <p id="contador">0</p>
    <button onclick="sumar()">Sumar +1</button>

    <script>
        let cuenta = 0;
        function sumar() {
            cuenta++;
            document.getElementById('contador').textContent = cuenta;
        }
    </script>
</body>
</html>

¿Qué hace este código?

  • HTML: crea la estructura (título, párrafo, botón).
  • CSS (etiqueta <style>): da color, tamaño y centra el contenido.
  • JavaScript (etiqueta <script>): escucha el clic del botón y aumenta el contador.
